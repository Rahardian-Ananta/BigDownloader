Privasi & Pemrosesan

Seluruh konversi format file (GeoJSON, Shapefile ZIP, GeoPackage, KML, Parquet, TopoJSON, CSV, GML) dilakukan 100% secara lokal di browser Anda. Geometri dan file hasil unduhan tidak pernah dikirim ke server pihak ketiga manapun.

Ketentuan Penggunaan

Aplikasi ini ditujukan untuk kebutuhan riset, pemetaan, edukasi, dan analisis data spasial. Selalu cantumkan atribusi resmi kepada Badan Informasi Geospasial (BIG) saat mempublikasikan hasil turunan peta.
